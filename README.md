# Jeux de lumière

Jeux de lumière plein écran qui réagissent à la musique, à afficher sur la télévision.

**Ouvrir l'application :** https://paulalainpichereau-create.github.io/jeux-de-lumiere/

- Sources : morceau de démo, fichiers audio, micro (pour Spotify, Deezer ou toute autre musique jouée dans la pièce), audio de l'écran (ordinateur).
- 26 scènes dont 6 pour les fêtes (Halloween, Noël, Nouvel An, Pâques, Saint-Valentin, Anniversaire), Boule à facettes, Chenillard, Nappe laser, Piste de danse, Aurore, Ambiance (éclairage de pièce) et MilkDrop (moteur de visualisation de Winamp, via [Butterchurn](https://github.com/jberg/butterchurn), licence MIT).
- Mode soirée, palettes de couleurs, tempo détecté, message et compte à rebours.
- Télécommande : le téléphone écoute la musique et pilote l’écran branché sur la TV (appairage par QR code, liaison directe WebRTC via [PeerJS](https://peerjs.com), licence MIT).
- Installable sur l'écran d'accueil (iPhone/iPad : Partager › Sur l'écran d'accueil ; Android : Installer l'application). Fonctionne hors connexion après la première ouverture.
